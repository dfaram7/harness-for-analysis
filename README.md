# Building an AI harness for intelligence analysis

Web version of the Public Insights paper on the controls built around large language models when they produce intelligence reports: rules, hooks, gates, ledgers, signed analyst approvals, and tests that prove a check can fail.

- Read it: https://dfaram7.github.io/harness-for-analysis/
- PDF: https://publicinsights.uk/hubfs/Building%20an%20AI%20harness%20for%20intelligence%20analysis%20(1).pdf

`index.html` is self-contained (no external fonts or scripts). The pipeline diagram is expected at `pipeline.png` beside it.
