# Building an AI harness for intelligence analysis

Web version of a practitioner article on the controls built around large language models when they produce intelligence reports: rules, hooks, gates, ledgers, signed analyst approvals, and tests that prove a check can fail.

Read it: https://dfaram7.github.io/harness-for-analysis/

`index.html` is self-contained (no external fonts or scripts). The pipeline diagram is expected at `pipeline.png` beside it.
